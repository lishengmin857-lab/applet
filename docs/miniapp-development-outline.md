# AI 文案润色爆款生成器 - 微信小程序开发大纲

## 1. 项目定位

本项目是一个面向小红书、朋友圈、短视频平台的 AI 文案润色小程序。

用户输入一段原始文案，选择目标平台风格和情绪调性后，系统生成可直接复制发布的爆款文案。

核心目标：

- 降低用户写文案的门槛
- 让生成结果具备平台发布价值
- 通过用户复制发布形成自然传播
- 先完成可上线 MVP，再逐步加入收藏、会员、分享奖励等增长功能

本开发大纲只覆盖微信小程序端的产品结构、页面规划、交互流程和前端开发任务。

不包含：

- 云函数实现
- AI 接口调用代码
- Prompt 拼接逻辑
- 服务端部署细节

以上内容后续可单独整理为后端接口文档。

## 2. MVP 核心功能

第一版只做最短闭环：

1. 用户输入原始文案
2. 用户选择文案风格
3. 用户选择情绪调性
4. 点击生成按钮
5. 展示生成结果
6. 用户一键复制
7. 保存本次生成记录

MVP 必须具备：

- 文案输入框
- 字数统计
- 粘贴文案
- 清空内容
- 风格选择
- 情绪调性选择
- 生成按钮 loading 状态
- 生成结果展示
- 一键复制结果
- 基础历史记录
- 错误提示和空状态

## 3. 页面结构

小程序建议采用 4 个 Tab：

```text
首页
文案记录
我的收藏
个人中心
```

### 3.1 首页

首页是核心转化页面，承担文案输入和生成操作。

页面模块：

- 顶部品牌区
- 文案输入区
- 风格选择区
- 情绪调性选择区
- 生成按钮
- 功能卖点提示
- 生成结果弹窗或结果面板

首页视觉方向：

- 活泼、年轻、强记忆点
- 按钮要突出，适合引导点击
- 输入区域要足够大，降低使用压力
- 不做复杂聊天框
- 不堆太多说明文字

### 3.2 文案记录

展示用户历史生成过的文案。

页面模块：

- 记录列表
- 风格标签
- 生成时间
- 原始文案摘要
- 生成结果摘要
- 复制按钮
- 收藏按钮
- 删除按钮

交互要求：

- 点击记录进入详情
- 支持再次复制
- 支持重新生成同类文案
- 无记录时展示空状态

### 3.3 我的收藏

展示用户收藏的优质文案。

页面模块：

- 收藏列表
- 文案详情
- 复制按钮
- 取消收藏按钮

交互要求：

- 点击查看完整文案
- 一键复制
- 取消收藏后从列表移除
- 无收藏时引导回首页生成

### 3.4 个人中心

展示用户账户、使用次数和运营入口。

页面模块：

- 用户头像和昵称
- 今日剩余次数
- 累计生成次数
- 会员入口
- 分享得次数
- 使用说明
- 联系客服
- 关于我们

第一版可以先做静态入口，会员和分享奖励后续补齐。

## 4. 首页详细结构

### 4.1 顶部品牌区

展示内容：

- 产品名称：AI 文案润色爆款生成器
- 副标题：一键润色 · 爆款生成 · 轻松出圈
- AI 插画或品牌图形

注意：

- 首屏要直接让用户知道这是文案生成工具
- 不做营销落地页式长介绍
- 不要让核心输入区被顶部区域挤到屏幕外

### 4.2 文案输入区

输入框提示语：

```text
把你想发的大白话贴在这里，哪怕只有几个字...
```

输入限制：

- 最大 1000 字
- 少于 3 字时不允许生成
- 超出字数时提示用户删减

辅助按钮：

- 粘贴文案
- 清空内容

状态展示：

- 当前字数 / 1000
- 输入为空时展示 placeholder
- 输入错误时展示轻提示

### 4.3 风格选择区

第一版保留 3 个核心风格：

```text
小红书风
高级感朋友圈
短视频脚本
```

可作为后续扩展的风格：

```text
微博热搜
知乎风格
抖音爆款
朋友圈卖货
职场汇报
探店种草
```

每个风格建议包含：

- 图标
- 风格名称
- 选中态
- 点击态

默认选中：

```text
小红书风
```

### 4.4 情绪调性选择区

第一版提供 3 个调性：

```text
幽默搞笑
真诚分享
专业干货
```

默认选中：

```text
真诚分享
```

交互建议：

- 使用标签按钮或横向单选
- 不要做复杂滑杆
- 保持选择成本低

### 4.5 生成按钮

按钮文案：

```text
一键生成爆款文案
```

按钮状态：

- 未输入：置灰，不可点击
- 可生成：高亮，可点击
- 生成中：显示 loading，禁止重复点击
- 生成失败：恢复可点击状态

点击前校验：

- 文案不能为空
- 文案不能少于 3 字
- 文案不能超过 1000 字
- 必须选择风格
- 必须选择调性

### 4.6 生成结果区

结果展示方式建议：

- 第一版使用底部弹窗或独立结果面板
- 结果内容要可长按复制
- 提供明确的一键复制按钮

结果区按钮：

- 复制文案
- 重新生成
- 收藏
- 关闭

复制成功提示：

```text
已复制，去发布你的爆款文案吧
```

## 6. 前端接口占位

此处只定义前端需要调用的能力，不展开云函数或后端实现。

### 6.1 生成文案

请求参数：

```js
{
  inputText: string,
  style: "xiaohongshu" | "moments" | "video",
  tone: "funny" | "sincere" | "professional"
}
```

返回数据：

```js
{
  id: string,
  resultText: string,
  remainCount: number
}
```

异常情况：

- 文案为空
- 文案过长
- 今日次数不足
- 内容不适合生成
- 服务繁忙

### 6.2 获取历史记录

请求参数：

```js
{
  page: number,
  pageSize: number
}
```

返回数据：

```js
{
  list: GenerationRecord[],
  hasMore: boolean
}
```

### 6.3 收藏或取消收藏

请求参数：

```js
{
  id: string,
  isFavorite: boolean
}
```

返回数据：

```js
{
  success: boolean
}
```

### 6.4 获取用户使用信息

返回数据：

```js
{
  dailyRemainCount: number,
  totalGenerateCount: number,
  isVip: boolean
}
```

## 8. 交互流程

### 8.1 首次进入

```text
进入首页
显示默认风格：小红书风
显示默认调性：真诚分享
输入框为空
生成按钮置灰
```

```text
输入文案
选择风格
选择调性

按钮进入 loading
生成成功
展示结果
保存记录
更新剩余次数
```

### 8.3 复制文案

```text
点击复制
写入剪贴板
提示复制成功
```

```text
点击重新生成
沿用当前输入、风格、调性

```

### 8.5 收藏文案

```text
点击收藏

按钮切换为已收藏
收藏页同步展示
```

## 10. 视觉规范建议

整体风格：

- 年轻
- 明亮
- 轻量
- 有 AI 工具感
- 强按钮引导

颜色建议：

- 主色：亮粉 / 紫色渐变
- 辅助色：荧光绿
- 背景色：暖白
- 文字色：黑色、深灰

按钮样式：

- 主要按钮使用强对比渐变
- 风格按钮使用描边 + 选中填充
- 选中态要明显
- 禁用态使用低饱和灰色

布局建议：

- 输入区优先级最高
- 风格按钮最多两行
- 生成按钮固定在首屏下方或输入区下方
- 不要让页面信息过载

## 14. 第一版验收标准

第一版完成后，应满足：

- 用户可以输入一段文案
- 用户可以选择一种风格
- 用户可以选择一种情绪
- 用户可以点击生成
- 用户可以看到生成结果
- 用户可以一键复制结果
- 用户可以查看历史记录
- 用户可以收藏生成结果
- 页面在常见手机尺寸下不明显错位
- 异常情况有明确提示

只要以上闭环跑通，就可以进入体验版测试。
